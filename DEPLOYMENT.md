# Safe Spaces AI Innovation Hub - Production Deployment Guide

This guide details how to host **Grafana** at `grafana.safespaceshub.com`, self-host **Stalwart Mail Server** for SMTP at `mail.safespaceshub.com`, and link with the Safe Spaces Cloud Vault at `filefran.safespaceshub.com`.

## 2. DNS Configuration

In your DNS manager (e.g. Cloudflare DNS, Route53, Namecheap), add the following records:

| Type | Host / Name | Value | TTL | Purpose |
|---|---|---|---|---|
| `A` | `grafana` | `<YOUR_VPS_IP>` | Auto / 300 | Grafana Web Platform |
| `A` | `mail` | `<YOUR_VPS_IP>` | Auto / 300 | Stalwart Mail Server |
| `A` | `filefran` | `<CLOUD_VAULT_IP>` | Auto / 300 | Safe Spaces Cloud Vault |
| `MX` | `@` (or `safespaceshub.com`) | `mail.safespaceshub.com` (Priority 10) | Auto / 300 | Email Routing |
| `TXT` | `@` | `"v=spf1 mx ip4:<YOUR_VPS_IP> ~all"` | Auto / 300 | SPF Anti-Spoofing |
| `TXT` | `default._domainkey` | `(Generated by Stalwart Admin UI)` | Auto / 300 | DKIM Signature |
| `TXT` | `_dmarc` | `"v=DMARC1; p=quarantine; rua=mailto:dmarc@safespaceshub.com"` | Auto / 300 | DMARC Policy |

## 3. VPS Firewall Configuration

On Ubuntu/Debian VPS, allow standard web, mail, and WebRTC SFU ports:

```bash
# Allow SSH
sudo ufw allow 22/tcp

# Allow Web & TLS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 443/udp # HTTP/3 QUIC

# Allow Stalwart Mail
sudo ufw allow 25/tcp   # SMTP Inbound/Relay
sudo ufw allow 587/tcp  # Submission STARTTLS
sudo ufw allow 465/tcp  # SMTPS
sudo ufw allow 993/tcp  # IMAPS

# Allow WebRTC SFU Media UDP Ports
sudo ufw allow 50000:50100/udp

# Enable Firewall
sudo ufw enable
```

## 4. Option A: Docker Compose Deployment (Recommended)

1. Clone or copy this repository to your VPS:
   ```bash
   git clone https://github.com/safespaceshub/grafana.git /opt/safespaces-grafana
   cd /opt/safespaces-grafana
   ```

2. Start the stack (Grafana + Stalwart + Caddy):
   ```bash
   docker compose up -d
   ```

3. Initialize Stalwart Mail Server:
   - Access Stalwart Web Admin at `http://<YOUR_VPS_IP>:8080`.
   - Complete the setup wizard for domain `safespaceshub.com`.
   - Create the system sender account: `grafana@safespaceshub.com`.
   - Copy the DKIM public key into your DNS TXT record.

## 5. Option B: Native Systemd Binary Deployment

If running directly on the host OS:

1. Build release binary:
   ```bash
   cargo build --release
   sudo cp target/release/grafana /usr/local/bin/safespaces-grafana
   sudo cp -r web /var/lib/safespaces-grafana/web
   sudo cp logo.png /var/lib/safespaces-grafana/logo.png
   sudo mkdir -p /var/lib/safespaces-grafana/data
   ```

2. Create systemd service `/etc/systemd/system/grafana.service`:
   ```ini
   [Unit]
   Description=Safe Spaces AI Innovation Hub - Grafana Conference Platform
   After=network.target

   [Service]
   Type=simple
   User=www-data
   WorkingDirectory=/var/lib/safespaces-grafana
   ExecStart=/usr/local/bin/safespaces-grafana
   Restart=always
   RestartSec=5
   Environment=GRAFANA_PORT=7878
   Environment=GRAFANA_PUBLIC_URL=https://grafana.safespaceshub.com
   Environment=GRAFANA_DOMAIN=grafana.safespaceshub.com
   Environment=SMTP_HOST=127.0.0.1
   Environment=SMTP_PORT=25
   Environment=SMTP_FROM=grafana@safespaceshub.com
   Environment=SMTP_NAME=Safe Spaces AI Innovation Hub
   Environment=FILEFRAN_URL=https://filefran.safespaceshub.com/api/v1/vault/sync

   [Install]
   WantedBy=multi-user.target
   ```

3. Enable and start:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now grafana
   ```
